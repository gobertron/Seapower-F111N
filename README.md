# RAN F-111N Naval Wing V7

V7 publication is in progress. The complete mod files have not yet been published to this branch.

The prepared release includes four aircraft families in 1980, 1985, 1995 and 2003 editions: 16 aircraft and 167 selectable loadout presets, with aircraft assets, textures, installers, authoring source, comparisons, references and Steam Workshop text.

The full release will be available here once the publication step is complete.
